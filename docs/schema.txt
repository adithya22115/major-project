MediCycle - Backend Schema & Architecture Document
Project: MediCycle – Smart Medicine Donation & Redistribution Platform
Version: 1.0
1. Backend Architecture
Presentation Layer (Controllers)        ↓Business Layer (Services)        ↓Persistence Layer (Repositories)        ↓PostgreSQL Database

3. Database Tables
users
id, name, email, phone, password, role_id, address, city, state, pincode, is_verified, created_at, updated_at
roles
id, role_name (DONOR, RECIPIENT, PHARMACY, ADMIN)
medicines
id, medicine_name, manufacturer, category, dosage, description, requires_prescription
medicine_donations
id, donor_id, medicine_id, quantity, batch_number, manufacture_date, expiry_date, condition, status, remarks, created_at
medicine_images
id, donation_id, image_url, image_type
prescriptions
id, donor_id, request_id, doctor_name, hospital_name, file_url, issued_date
verification
id, donation_id, verified_by, verification_date, result, remarks
inventory
id, medicine_id, available_quantity, reserved_quantity, distributed_quantity, expired_quantity, updated_at
medicine_requests
id, recipient_id, medicine_id, requested_quantity, prescription_id, status, approved_by, created_at
notifications
id, user_id, title, message, type, is_read, created_at
audit_logs
id, user_id, action, entity_name, entity_id, timestamp
