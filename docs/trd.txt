Technical Requirements Document (TRD)
Project: MediCycle – Smart Medicine Donation & Redistribution Platform
Version: 1.0
Prepared For: Major Project
1. Purpose
This Technical Requirements Document defines the technical architecture, technology stack, system components, APIs, database, security, deployment strategy, and development standards for MediCycle.
2. System Architecture
Client (React + Tailwind CSS)        │ HTTPS REST APIs        │Spring Boot Backend        │Service Layer        │Repository Layer (JPA/Hibernate)        │PostgreSQL Database        │Cloudinary (Medicine Images)
