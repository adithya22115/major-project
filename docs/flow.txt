MediCycle - Website Flow Document
Project: MediCycle – Smart Medicine Donation & Redistribution Platform
Purpose: Defines the complete website navigation, user journeys, and module workflows.
Version: 1.1 (Updated with location-based features)

1. User Roles
Donor (Patient)
Recipient (Patient)
Pharmacy / NGO
Administrator

2. Landing Page
Navigation:• Home• About• How It Works• Medicines• FAQ• Contact• Login / Register
Hero Section:"Reduce Medicine Waste. Help Someone in Need."
Primary Actions:• Donate Medicine• Find Medicines
Additional Sections:• How It Works• Platform Statistics• Partner Pharmacies/NGOs• Footer

3. Authentication Flow
Home↓Login / Register↓Select Role↓Donor / Recipient / Pharmacy / Admin↓Role-specific Dashboard

4. Donor Flow
Dashboard↓Donate Medicine↓Enter Medicine Details (incl. pincode/location)↓Upload Images & Prescription (if applicable)↓Submit Donation↓Status: Pending Verification↓Approved / Rejected↓Approved medicines are added to the Medicine Pool (associated with donor's pincode)

5. Recipient Flow
Dashboard↓Search Medicines (by name/category/pincode)↓View Medicine Details (including availability at nearby pincodes)↓Submit Request↓Upload Prescription (if required)↓Request Review↓Approved↓Collect Medicine (donor/pharmacy location info shown)

6. Pharmacy / NGO Flow
Dashboard↓Pending Donations (view donor location/pincode)↓Review Donation↓Verify Expiry, Packaging & Details↓Approve / Reject↓Approved medicines added to Inventory (tagged with pincode)↓Review Recipient Requests (show requester pincode for proximity)↓Approve Distribution↓Update Inventory (reduce available quantity)

7. Admin Flow
Dashboard↓Manage Users (view location stats)↓Manage Medicines↓View Reports (geographic distribution)↓Manage Verification Records↓Platform Settings (configure pincode validation service)

8. Navigation Menu by Role
Donor
Dashboard, Donate Medicine, My Donations, Notifications, Profile
Recipient
Dashboard, Medicine Pool (search by pincode), My Requests, Notifications, Profile
Pharmacy
Dashboard, Pending Donations (with location), Inventory (by pincode), Requests, Reports, Profile
Admin
Dashboard, Users, Medicines, Verification, Reports, Settings

9. Core Workflows
Donation Workflow:Donor → Submit Donation (with pincode) → Verification → Approved → Medicine Pool (indexed by pincode)
Request Workflow:Recipient → Search (by pincode) → Request → Pharmacy Approval → Distribution (notify donor location)
Inventory Workflow:Approved Donation → Inventory Updated (pincode-tagged) → Distribution → Inventory Reduced (per pincode)
Location Workflow:User enters pincode → System validates via PincodeLookupService → Suggests city/state → Saved with profile/donation

11. Overall System Flow
Landing Page↓Login / Register↓Role-Based Dashboard↓Donation / Search (with pincode) / Verification↓Medicine Pool (pincode-indexed)↓Request & Approval↓Distribution↓Inventory Updated (per pincode)↓Location Analytics (admin)

12. UI Recommendation
Use a common application layout after login with a shared top navigation and sidebar. Menu items should change dynamically based on the logged-in user's role to ensure consistency and reduce duplicated UI code.
Include pincode input fields with auto-suggestion and validation (using integrated pincode API).
Display distance or "nearby" labels based on pincode matching.
