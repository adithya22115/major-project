MediCycle - Implementation Plan
Project: MediCycle – Smart Medicine Donation & Redistribution Platform
Duration: 6 Weeks (College MVP)
Methodology: Agile (Weekly Milestones)
1. Project Phases
Phase 1 - Planning (Week 1)
Finalize PRD, TRD and Website Flow
Prepare UI wireframes
Design ER Diagram and database schema
Set up GitHub repository
Create React, Spring Boot and PostgreSQL projects
Phase 2 - Authentication & Foundation (Week 2)
Implement JWT authentication
Role-based authorization
User registration/login
Common dashboard layout
Swagger configuration
Phase 3 - Medicine Donation Module (Week 3)
Donation form
Medicine image upload
Prescription upload
Donation history
Donation status tracking
Phase 4 - Verification & Inventory (Week 4)
Pharmacy verification dashboard
Approve/Reject donations
Inventory updates
Medicine pool listing
Search and filters
Phase 5 - Medicine Request Module (Week 5)
Recipient dashboard
Medicine request workflow
Request approval
Notifications
Profile management
Phase 6 - Testing & Deployment (Week 6)
Bug fixing
Unit and integration testing
Deployment
Documentation
Final presentation preparation

Users can register and login.
Donors can submit medicine donations.
Pharmacy can verify donations.
Approved medicines appear in the medicine pool.
Recipients can request medicines.
Inventory updates automatically.
Admin can manage users and reports.
