1. PASSWORD HASHING
--------------------------------------------------------------------

All passwords are hashed using BCrypt via BCryptPasswordEncoder.

BCrypt is a salted one-way hash. The original password CANNOT be
recovered - only the hash is stored.

Example hash: $2a$10$N9qo8uLOickgx2ZMRZoMyeIjZAgcfl7p92ldGxad68LJZdL17lhWy
  $2a     = algorithm (BCrypt)
  10      = cost factor (2^10 rounds)
  salt    = next 22 chars
  rest    = salted hash

Code: SecurityConfig.java -> BCryptPasswordEncoder bean

Currently Admin password is "Adithya@123", stored as a BCrypt hash
in the users.password column. You cannot reverse it.

  1. Open a terminal

  3. Visit http://localhost:8085/h2-console
  4. JDBC URL: jdbc:h2:mem:medicycle;DB_CLOSE_DELAY=-1;MODE=PostgreSQL
  5. User: sa, Password: (empty)

4. SAMPLE SQL QUERIES
--------------------------------------------------------------------

-- Users with roles:
SELECT u.id, u.name, u.email, r.role_name, u.is_verified, u.failed_login_attempts, u.locked_until
FROM users u
JOIN roles r ON u.role_id = r.id;

-- Recent audit log:
SELECT action, entity_name, timestamp
FROM audit_logs
ORDER BY timestamp DESC
LIMIT 10;

-- Active refresh tokens for a user:
SELECT rt.token, rt.expires_at, rt.revoked
FROM refresh_tokens rt
JOIN users u ON rt.user_id = u.id
WHERE u.email = 'admin@medicycle.com' AND rt.revoked = false;

5. ACCESSING FROM OTHER SYSTEMS (REMOTE ACCESS)
--------------------------------------------------------------------

To access the MediCycle database from another computer on your network, follow these detailed steps:

🔧 PART 1: PREPARE THE SERVER COMPUTER
(This is the computer where your MediCycle backend is running)

Step 1: Locate PostgreSQL Configuration Files
1. Open File Explorer
2. Navigate to: C:\Program Files\PostgreSQL\ [version number] \data\
   (Example: C:\Program Files\PostgreSQL\16\data\)
   If you installed via another method, check your installation directory for a "data" folder
3. Inside this "data" folder, you'll find two key files:
   - postgresql.conf
   - pg_hba.conf

Step 2: Configure postgresql.conf (Listen for Connections)
1. Right-click postgresql.conf → Open with → Notepad
2. Press Ctrl+F and search for: listen_addresses
3. You'll likely see: #listen_addresses = 'localhost'
4. Change this line to exactly: listen_addresses = '*'
   (Remove the # and change localhost to *)
5. Save the file (Ctrl+S)

Step 3: Configure pg_hba.conf (Allow Connections)
1. In the same folder, open pg_hba.conf with Notepad
2. Scroll to the very bottom of the file
3. Add this new line at the end:
   host    all             all             0.0.0.0/0               md5
4. Save the file

💡 What these changes do:
- postgresql.conf: Tells PostgreSQL to listen for connections from any network address (*) instead of just localhost
- pg_hba.conf: Allows any IP address (0.0.0.0/0) to connect using password authentication (md5)

Step 4: Restart PostgreSQL Service
1. Press Windows key + R, type services.msc, press Enter
2. Find: PostgreSQL 16 (or your version)
3. Right-click → Restart (or Stop → wait 5 seconds → Start)
4. Wait for status to show "Running"

💻 PART 2: CONNECT FROM ANOTHER COMPUTER
(This is your laptop, another PC, or any device on the same network)

Step 1: Find the Server's IP Address
On the SERVER computer:
1. Press Windows key + R → type cmd → Enter
2. Type: ipconfig → Enter
3. Look for your active network connection (Wi-Fi or Ethernet)
4. Find: IPv4 Address. . . . . . . . . . . : 192.168.x.x
5. Copy this IP address (you'll need it shortly)

Step 2: Install a Database Client (Recommended: pgAdmin)
On your CLIENT computer:
1. Go to: https://www.pgadmin.org/download/
2. Download pgAdmin for Windows
3. Run the installer (accept all defaults)
4. Launch pgAdmin when finished

Step 3: Create the Connection in pgAdmin
1. In pgAdmin, look at the left panel → right-click "Servers" → Create → Server...
2. General tab:
   - Name: MediCycle Database (or any name you prefer)
3. Connection tab:
   - Host name/address: [PASTE THE SERVER IP YOU COPIED]
   - Port: 5432
   - Maintenance database: medicycle
   - Username: postgres
   - Password: Adithya@123
4. Click Save

Step 4: Browse Your Data
1. In the left panel, expand: Servers → MediCycle Database → Databases
2. Double-click on "medicycle"
3. Expand: Schemas → public → Tables
4. Right-click any table (e.g., "users") → View/Edit Data → All Rows
5. You should now see your MediCycle data!

🔒 IMPORTANT SAFETY NOTES

For Home/Testing Networks (Recommended):
Instead of 0.0.0.0/0 in pg_hba.conf, use your specific home network range:
1. Find your network's IP range (usually looks like 192.168.1.x or 10.0.0.x)
2. Change the pg_hba.conf line to:
   host    all             all             192.168.1.0/24          md5
   (Replace 192.168.1.0/24 with your actual network - ask someone tech-savvy if unsure)
3. This only allows devices on your home Wi-Fi to connect

Never Do This in Production:
- Leaving 0.0.0.0/0 if your computer is directly connected to the internet
- Sharing your PostgreSQL password publicly
- For real applications, use SSH tunneling or VPNs (more advanced but safer)

Quick Security Test:
After connecting successfully, try connecting from a different network (like your phone's hotspot). If it fails, your settings are safely restricted to your local network only.

6. TROUBLESHOOTING COMMON ISSUES
--------------------------------------------------------------------

| Problem | Likely Cause | Solution |
|---------|--------------|----------|
| could not connect to server: Connection refused | PostgreSQL not listening/restarted incorrectly | Double-check postgresql.conf edit and service restart |
| password authentication failed for user "postgres" | Wrong password | Verify password is Adithya@123 (check database-guide.txt) |
| no pg_hba.conf entry for host | Client IP not allowed | Check pg_hba.conf - ensure your client's IP range is covered |
| could not connect to server: Connection timed out | Wrong server IP or network issue | Verify correct server IP; ensure both computers on same network |
| database "medicycle" does not exist | Wrong database name | Confirm it's exactly medicycle (case-sensitive!) |
